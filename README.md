# Relic Revealer

Adds two popup UIs for tracking a world's relics and viewing its cherubim.

Includes options to have the UI popup displayed immediately after world-gen, immediately after loading a save, and by use of two activated abilities (one each for relics and cherubim).

Wish for `UD AskReveal` to display the base UI, or `UD RevealRelics` or `UD RevealCherubim` for the individual UIs.
